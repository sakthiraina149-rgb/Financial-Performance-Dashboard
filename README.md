# 📊 Financial Performance Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Financial Performance Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes financial performance for **2013–2014**, providing insights into sales, profit, profit margin, units sold, country-wise performance, segment-wise performance, and monthly sales trends.

The main objective of this project is to transform financial data into meaningful and interactive business insights using Power BI and DAX.

---

## 🎯 Project Objectives

- Analyze total sales and total profit
- Evaluate overall profit margin
- Analyze sales performance by country
- Compare profit margins across business segments
- Identify monthly sales trends
- Analyze Year-over-Year sales growth
- Track total units sold
- Create an interactive financial performance dashboard

## 📊 Dashboard Analysis

The dashboard includes the following visualizations:

### Sales & Profit Analysis
Comparison of sales and profit over time to understand financial performance trends.

### Monthly Sales Trend
A trend analysis showing how sales performance changes across different months.

### Country-wise Sales Performance
Comparison of total sales across different countries.

### Segment-wise Profit Margin
Analysis of profit margins across different business segments.

### Segment-wise Sales
Visualization of sales contribution from different business segments.

### Interactive Filters
The dashboard includes filters for:

- Year
- Country
- Segment

These filters allow users to interactively explore different areas of the financial data.
